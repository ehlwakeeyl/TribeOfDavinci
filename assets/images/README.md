# Images

Drop real Clean Shelters Ltd photography into this folder to replace the
"IMAGE PLACEHOLDER" blocks used throughout the site.

Recommended shots:
- Immaculate homes, modern kitchens, bathrooms
- Office and commercial environments
- Cleaning professionals at work
- Before/after cleaning pairs
- Premium Abuja properties

Placeholders use standard aspect ratios (4:3, 4:5, 3:4, 16:10) so real
photography can be dropped in without changing page layouts. To swap a
placeholder for a real image, replace the `.placeholder-frame` container's
contents with an `<img>` tag pointing to a file in this folder.
